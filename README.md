# 🧮 CalX — Chrome Calculator Extension

CalX is a lightweight and user-friendly Chrome extension that provides quick calculations directly from the browser toolbar. It is designed for fast and convenient everyday use without opening a separate calculator application.

## ✨ Features

* Basic arithmetic operations
* Addition, subtraction, multiplication and division
* Clear and delete controls
* Decimal-number support
* Keyboard-friendly controls
* Responsive popup interface
* Lightweight and fast
* Works locally without collecting personal data

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chrome Extension API

## 🚀 Installation

1. Download or clone the repository.
2. Extract the ZIP file.
3. Open Google Chrome.
4. Visit `chrome://extensions/`.
5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select the CalX project folder.
8. Pin CalX from the extensions menu.

## 💻 How to Use

1. Click the CalX icon in the Chrome toolbar.
2. Enter numbers using the buttons or keyboard.
3. Choose an arithmetic operator.
4. Press `=` to view the result.
5. Use `C` to clear the calculation.

## 🔐 Privacy

CalX performs calculations locally inside the browser. It does not collect, store or share personal information.
